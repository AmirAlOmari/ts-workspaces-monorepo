# 6. CI

Prev: [5. Testing](05-testing.md) · Next: [7. Benchmarks](07-benchmarks.md) · Index: [book](README.md)

The target is a private self-hosted GitLab; GitHub Actions runs meanwhile. Both files are kept and must stay in sync.

## GitHub Actions (`.github/workflows/ci.yml`)

- `build` job, matrix TypeScript 7.0.2 and 6.0.3: install with the frozen lockfile, swap the compiler for this job, restore the `dist` + `tsbuildinfo` cache, then `pnpm typecheck`, `pnpm fmt:check && pnpm lint`, `pnpm typecheck:tests && pnpm test`, assert a second `tsc -b` rebuilds nothing, run the CLI from `dist` and from source through the condition.
- `vitest` job: `pnpm vitest:test` (opt-in).
- `vite-poc` job: `pnpm vp:check`, `vp:test`, `vp:build` (opt-in).

The cache key is `tsc-<ts>-<lockfile hash>-<sha>` with a restore prefix, so each run starts from the latest build outputs. Restoring `dist` without `tsbuildinfo` (or the reverse) forces a rebuild, hence one entry.

## GitLab (`.gitlab-ci.yml`)

Image `node:24`, `corepack enable`, the pnpm store cached under `.pnpm-store` keyed by lockfile, and a separate cache for `dist` + `tsbuildinfo` with a hand-bumped `BUILD_CACHE_VERSION`. The build job runs install, `typecheck`, `fmt:check`, `lint`, `typecheck:tests`, `test`. `dist` is exported as an artifact for downstream jobs.

**Untested on a real GitLab instance:** cache and artifact behaviour, runner Node/corepack setup, and the TS 6 matrix (GitLab has no matrix wired yet; use `parallel: matrix` when you add it). GitHub cross-run cache restore is also not verified.

## Rules

- `pnpm check` reproduces the gate locally.
- Tests on `--test-force-exit` so a leaked handle cannot hang a pipeline.
